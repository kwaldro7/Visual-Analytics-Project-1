# 🚖 Uber Ride Data Analysis

## 📌 Project Overview
This project is a **class assignment** focused on analyzing a dataset of Uber ride bookings.  
It walks through the full data analysis workflow, including **data preprocessing, exploration, and visualization** to uncover patterns and trends in ride behavior.

---

## 📂 Contents
- **Data Preprocessing**  
  Cleaning and preparing the raw data for analysis using **pandas**.
- **Exploratory Data Analysis (EDA)**  
  Investigating key variables, distributions, and relationships between features.
- **Visualizations**  
  Creating insightful charts and plots using **matplotlib** to support findings.
